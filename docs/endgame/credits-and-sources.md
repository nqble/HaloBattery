# Credits and evidence boundaries

- **Janlhin** maintains the [Endgame Gear Web Configurator](https://github.com/Janlhin/Endgame_Gear_Web_Configurator). The public [XM2we issue #1](https://github.com/Janlhin/Endgame_Gear_Web_Configurator/issues/1) records Janlhin's protocol investigation, configurator fixes and collaboration with nqble. That project is an external source, not a component authored by nqble.
- **[Mqtteo0](https://github.com/Mqtteo0)** independently tested the original XM2w 4k Stage D candidate: battery agreement with the official tool, charging display and percentage recovery after cable removal. See the [public results](https://github.com/ahmedkhursheed23/HaloBattery/issues/48#issuecomment-6716473809) and [permission to summarize and credit](https://github.com/ahmedkhursheed23/HaloBattery/issues/48#issuecomment-6716900302). Mqtteo0 reported recovery after standby on [November 9](https://github.com/ahmedkhursheed23/HaloBattery/issues/48#issuecomment-6742865971), but [reported on November 10](https://github.com/ahmedkhursheed23/HaloBattery/issues/48#issuecomment-6764152209) that opening the official tool now seemed necessary. Detection recovery remains inconsistent and unresolved; the proposed mechanism is not attributed to Mqtteo0. This credit covers the reported observations, not protocol research or checks they did not report.
- **nqble** performed the XM2we owner tests and prepared the HaloBattery contribution and experimental integration with GPT assistance. AI-generated changes require review and hardware validation.
- **HaloBattery's upstream and community maintainers** provide the application and integration framework. This fork is not an official Endgame Gear project.
- **Vole contributors** provide additional public [protocol documentation](https://github.com/johanneszab/vole). Check the repository for current paths and attribution before reusing code.

This documentation summarizes nqble's observations and links to already-public discussions. It does not publish private Discord messages, third-party reports, source attachments or logs. Any future such material needs publication scope and attribution agreed with its contributor. Independently public facts should cite their public source.

Public references do not grant blanket permission to copy code: applicable source licenses and notices still matter. A public findings table is distinct from redistributing a tool or raw evidence pack.
