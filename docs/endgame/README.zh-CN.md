# Endgame Gear 电池测试结果

[English](README.md) | 简体中文

由 [nqble](https://github.com/nqble) 在此 HaloBattery 分支中维护。
本记录仅包含特定测试与实施工作的相关信息，并非 Endgame Gear 的官方资源，也不代表所有 XM/OP1 型号均受支持。

## 如何阅读本记录

先查看下方的型号表，再打开对应型号页面，了解测试版本、观察结果和限制。请区分型号：XM2we、第一代 XM2w 4k 以及 XM2w 4k v2 不可互换。某一型号的结果不能证明其他型号也受支持。

设备持有者的观察结果描述了在真实设备上发生的情况。自动化或模拟检查用于测试软件行为，但并不能证明该软件在该设备上能够正常运行。发布状态表示代码已合并或发布的位置；仅通过测试并不会更改该状态。

Stage D 是本次协作的便携式 HaloBattery 应用测试的名称，不是 HaloBattery 的发布版本号或认证。第一代型号和 v2 Stage D 下载对应不同的构建版本。

## 型号状态

本记录已收录公开结果，包括 nqble 的 XM2we 测试和 Mqtteo0 的第一代 XM2w 4k 观察。Janlhin 私下提供的硬件测试结果，将在 Janlhin 批准最终公开措辞后补充。这项审核要求不影响已经公开或另获发布许可的结果。

| 型号 | 本记录中的证据 | 状态 |
| --- | --- | --- |
