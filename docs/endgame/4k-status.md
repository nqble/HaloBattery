# Experimental 4K integration status

An XM2w4kv2-focused portable HaloBattery integration build is available for review:
[Stage D release](https://github.com/nqble/HaloBattery/releases/tag/xm2w4kv2-stage-d-r1).

Jordan prepared the candidate implementation with GPT assistance. It has local automated validation, but no returned hardware validation of this integrated tray build is recorded here. Neither this document nor a release tag establishes support for all4K models.

The next checks concern tray detection/name, comparison with the official tool in separate runs, charging display, cable/wireless handover, natural sleep and movement wake, receiver reconnection and duplicate icons. These are planned checks, not reported passes.

Public protocol context is available in [Janlhin's configurator](https://github.com/Janlhin/Endgame_Gear_Web_Configurator) and [Vole](https://github.com/johanneszab/vole). Read their scope and hardware caveats; do not assume the WE and4K protocol families are interchangeable.

Private correspondence and unpublished reports/logs are not reproduced or summarized as public hardware evidence here. Additional model-specific findings will be added only after their publication scope is agreed.
