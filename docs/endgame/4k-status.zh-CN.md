# 实验性 4K 集成状态

面向 XM2w4kv2 的便携 HaloBattery 集成构建可供审阅：
[Stage D 发布页](https://github.com/nqble/HaloBattery/releases/tag/xm2w4kv2-stage-d-r1)。

nqble 使用 GPT 辅助准备候选实现，并完成本地自动化验证。本记录尚无该托盘构建的返回真机结果，也不能据此确认所有4K型号兼容。

下一步计划检查识别/名称、与官方工具分开运行的电量对照、充电显示、有线/无线切换、自然休眠和移动唤醒、接收器重连及重复图标。这是计划，不是已通过的结果。

公开协议背景见 [Janlhin 的配置器](https://github.com/Janlhin/Endgame_Gear_Web_Configurator)和 [Vole](https://github.com/johanneszab/vole)。请注意各自的验证范围；WE 与4K不能视为同一协议。

本文不公开私人通信或未获同意公开的报告、日志及其中的硬件结论。更多具体型号结果将在确认公开范围后补充。
